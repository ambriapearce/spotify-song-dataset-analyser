# Spotify Analysis Throughout the Years: 1998-2020

This project analyses a dataset of songs, artists and genres to explore how music trends and preferences have changed between **1998 and 2020**. The analysis investigates patterns in song popularity, musical characteristics, genres and top performing artists. 

---

## Project Objectives

The project was designed to:

- Explore changes in music trends between 1998 and 2020.
- Investigate the popularity of different genres over time.
- Examine the performance of artists across different periods.
- Analyse relationships between musical characteristics and song popularity.
- Develop a simple method for identifying songs with similar attributes.
- Provide an interactive interface for exploring the dataset.
