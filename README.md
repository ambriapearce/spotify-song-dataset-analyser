# Spotify analysis throughout the years: 1998 to 2020

A dataset of songs, artists and genres explores how popular genres, music tastes and top performing artists have evolved over time. It highlights patterns such as the influence of top artists across decades and the rise of certain genres. 


---
## Folder Structure 📂

**'data/'** : Raw data used for this analysis.  
**'scripts/'** : Custom modules.  
**'.gitignore'** : Files to ignore.  
**'menu.ipynb'** : Interactive menu interface.

---

## Viewing 👓

To use the Spotify Analysis, follow these steps.

1. **Clone the Repository**
2. **Open the file menu.ipynb in Jupyter Notebook**
3. **Install required packages: !pip install ipywidgets**

This project also uses custom modules included in the repository:
- Genre.py
- Artists.py
- Top5.py

4. **Run the Notebook**
Use the menu interface to explore different parts of the Spotify Dataset.
